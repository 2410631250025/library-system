# Library System

## Description
Library System adalah aplikasi sistem informasi perpustakaan sederhana berbasis Laravel dengan MySQL sebagai database.

## Requirements
- PHP
- Composer
- MySQL
- Laravel

## Installation
1. Clone repository
2. Install dependencies
3. Setup environment
4. Setup database
5. Run migration
6. Run laravel
7. Buka aplikasi di browser http://127.0.0.1:8000/
